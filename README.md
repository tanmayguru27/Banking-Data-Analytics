Banking Data Analytics Project
A SQL and Python analytics project exploring customer demographics,
income, deposits, loans, savings, credit-card balances, loyalty
segments, and risk-weighting patterns.
Project Overview
The goal of this project is to practice translating a customer banking
dataset into useful business questions, answer those questions with SQL,
and communicate patterns through Python analysis and visualizations.
The project combines: - MySQL for querying and aggregating customer
data. - Python and Pandas for data retrieval, summary metrics, and
analysis. - Matplotlib and Seaborn for visual exploration.
Important: This is an exploratory portfolio project using a
customer dataset. The analysis is descriptive, not a validated
credit-risk model, and it should not be used to make real lending
decisions.

Questions Explored
Customer and demographic analysis
- How many customers are in the dataset?
- How are customers distributed by nationality, occupation, fee
  structure, and loyalty classification?
- What are the age ranges and average ages across groups?
Income analysis
- What is the average estimated income?
- Which customers have the highest and lowest estimated incomes?
- How does average income vary by occupation, nationality, and loyalty
  classification?
Deposits, loans, savings, and credit
- What are total and average deposits and loans?
- How do deposits and loans vary by occupation, nationality, and
  loyalty classification?
- Which customers have the highest balances?
- How do savings, deposits, and credit-card balances compare?
Risk and loyalty
- How does customer count vary by risk weighting?
- How do average loans, deposits, and estimated income vary by risk
  weighting?
- Which loyalty classifications contribute the most deposits or have
  the highest average income?
Intermediate SQL techniques
The SQL scripts practice GROUP BY, HAVING, subqueries, sorting and
limiting results, aggregate functions, RANK(), DENSE_RANK(),
ROW_NUMBER(), and PARTITION BY.
